# Panadería - Restaurante | Página funcional

Proyecto web funcional basado en el diseño visual aprobado.

## Funciones incluidas
- Navegación por secciones.
- Menú completo con productos y categorías.
- Filtro por categoría.
- Productos destacados.
- Modal de detalle de producto.
- Carrito de compras funcional.
- Aumentar/disminuir cantidades y eliminar productos.
- Cálculo automático del total.
- Persistencia del carrito con localStorage.
- Botón de preparación de pedido.
- Enlace de ubicación a Google Maps.
- Menú responsive para celular.
- Botones de contacto preparados para conectar redes/WhatsApp.

## Para probarlo
Abre `index.html` en un navegador.
